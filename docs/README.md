# Sky Bounce - Game Company Operations Manual

## Company Overview

Sky Bounce is a mobile-first hyper-casual arcade game built with HTML5 Canvas and vanilla JavaScript. The entire product — code, graphics, audio — is procedurally generated with zero external assets, enabling instant-load gameplay on any browser.
